# Esercizio OOP - 13-01-2025
Sviluppare i seguenti punti rispettando le buone regole dell'OOP, tra i quali incapsulamento e modularità dei metodi.
1. Implementare una classe Student, definita da identificativo, nome e media dei voti. La media è un numero in virgola mobile compreso fra 0 e 5.
2. Creare nel main un array di 4 oggetti Student.
3. Stampare nel main l'id dello studente con la media più alta e quello con la media più bassa.
